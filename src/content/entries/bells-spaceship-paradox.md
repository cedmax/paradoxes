problem: "Two spaceships joined by a string speed up in exactly the same way at the same moment. Does the string break?"
claimA: "Keeping the ships the same distance apart means the string cannot stretch."
claimB: "The ships stay the same distance apart as seen from launch, yet the string stretches."
verdict: "Keeping the ships’ gap fixed in the launch frame stretches the string: an unstretched moving string would be measured shorter in that frame. If the ships keep speeding up, it breaks."
whatBreaks: "The assumption that if the gap between the ships does not change, a string across it is not stretched."
statusNote: "keeping the gap fixed in the launch frame does not prevent stress. The standard result is that the string breaks if the ships keep speeding up, though the best description of the cause has been debated."
setup: "Two spaceships sit one behind the other with a taut string between them. They start together and speed up in exactly the same way, as seen from where they launched. Their gap therefore stays fixed in that view. Does the string remain unstretched?"
whyWrong: "The gap is just space between programmed ships. It is not an object that must shrink as it moves. The string is an object. Its unstretched rest length stays the same, but an unstretched string moving with the ships would be measured shorter in the launch frame as their speed rises. Holding it across the unchanged gap stretches it."
resolution:
  - "An unchanged gap does not mean an unstretched string. As the ships gain speed, the gap exceeds the launch-frame length an unstretched moving string would have. If they keep speeding up, the string breaks."
  - "In a frame moving with the ships, the description differs: their separation grows. Both descriptions predict stress in the string. Keeping their separation fixed in their own view would require the front ship to accelerate more gently than the rear ship."
finePrint: "The “launch frame” is the viewpoint in which both ships begin at rest. Moving observers disagree about which distant events happen simultaneously, so fixed separation in that frame need not mean fixed separation in a frame moving with the ships. The string’s unstretched rest length does not change. In the idealised account, the speed reached determines the stretch, and the material strength determines when it breaks; a small increase in speed need not snap it. A detailed material model would also account for acceleration and elastic response. Dewan and Beran described the puzzle in 1959 and Bell popularised it in 1976. Some authors who agree on the breaking dispute whether length contraction should be called its cause. The entry gives the standard kinematic explanation, not a model of a particular material."
