problem: "Two spaceships joined by a string speed up in exactly the same way at the same moment. Does the string break?"
claimA: "The gap between the ships stays the same length, so a string that spanned it at the start is never stretched."
claimB: "A moving string is shorter than the same string at rest, so a string spanning a gap that does not shrink is stretched until it breaks."
verdict: "The string breaks. The gap between the ships keeps its length, but the moving string would naturally be shorter, so it is pulled tighter and tighter until it snaps."
whatBreaks: "The assumption that if the gap between the ships does not change, a string across it is not stretched."
statusNote: "the idea that a gap of unchanging length cannot stretch the string is wrong. The string would contract with its motion and the gap does not, so the string is put under stress and breaks. Most publications agree on this. A few earlier authors argued that the string would not break, and some who agree that it breaks dispute how to describe the cause."
setup: "Two identical spaceships sit at rest, one behind the other, facing the same way. A string joins them and is just taut. At an agreed moment both start their engines and speed up in exactly the same way, as seen from the frame they started in, called the launch frame here. In that frame the two ships always have the same speed, so the distance between them never changes. Special relativity says that moving objects are measured as shorter in the direction they move, an effect called length contraction. Does the string break? Edmond Dewan and Michael Beran described the set-up in 1959, and John Bell made it widely known in 1976."
whyWrong: "It seems the string should be fine, since it joins two points whose distance never changes. The slip is to treat the gap and the string alike. The gap is not an object. It is just the space between two ships, and in the launch frame it keeps its length because the ships are programmed to move identically. The string is an object, and like the ships it would contract as it speeds up, if nothing held it. A shorter string cannot span an unchanged gap, so it must be stretched. Bell reported that when the question was put, in an informal survey, to people at CERN, the European particle physics laboratory, there was a “clear consensus” that the string would not break. He said this was wrong, and that “many people who get the wrong answer at first get the right answer on further reflection”."
resolution:
  - "In the launch frame, the gap stays fixed while the string, now moving, would naturally be shorter. The faster the ships go, the further the string is stretched beyond its natural length. At about 87 percent of the speed of light the contraction factor is two, so the string would have to stretch to twice its natural length to span the gap. Real strings break long before that."
  - "Seen from the ships, the story is told differently but ends the same way. At each moment the crews are at rest in a frame moving with them. In that frame the two ships did not start their engines at the same moment, because observers in relative motion disagree on which distant events happen together, the same effect behind the [ladder paradox](ladder-paradox). So the distance between the ships, as the crews measure it, grows. In Bell’s account, one ship sees the other “drifting further and further behind”, and a given piece of string can no longer span the distance."
  - "Both accounts agree: the string breaks. For the string to survive, the front ship would have to accelerate a little more gently than the rear one, so that the distance between them, as measured by the ships, stays fixed. Motion of that kind is called Born rigid. With identical accelerations in the launch frame, it is not, so the first claim is false. An unchanging gap does not mean an unstretched string."
finePrint: "Dewan and Beran wrote in 1959 that a stress must form until, at high enough speeds, the thread “finally reaches its elastic limit and breaks”. Bell’s 1976 version, in the essay “How to teach special relativity”, used three ships: a signal from a ship that stays at rest starts the other two at once. The answer has been argued over more than once. Nawrocki gave three arguments in 1962 that the string would not break, and Dewan replied in 1963 that his analysis stood. Matsuda and Kinoshita reported much criticism, written in Japanese, after publishing their own rediscovery of the puzzle in 2004. Franklin and Petkov, in 2009, agreed that the string breaks but rejected the idea that length contraction causes the stress, putting it down to the unequal accelerations seen from the ships. That is a dispute about how to describe the cause, not about the outcome. In the idealised case with no string at all, the ships simply keep their distance in the launch frame."
