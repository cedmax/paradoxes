problem: "Two spaceships joined by a string speed up in exactly the same way at the same moment. Does the string break?"
claimA: "The gap between the ships stays the same length, so a string that spanned it at the start is never stretched."
claimB: "A moving string is shorter than the same string at rest, so a string spanning a gap that does not shrink is stretched until it breaks."
verdict: "The string is stretched. The ships keep their gap fixed in the launch frame, while the moving string’s natural length shrinks. With enough acceleration, it breaks."
whatBreaks: "The assumption that if the gap between the ships does not change, a string across it is not stretched."
statusNote: "keeping the gap fixed in the launch frame does not prevent stress. The standard result is that enough acceleration breaks the string, though the best description of the cause has been debated."
setup: "Two spaceships sit one behind the other with a taut string between them. They start together and speed up in exactly the same way, as seen from where they launched. Their gap therefore stays fixed in that view. Does the string remain unstretched?"
whyWrong: "The gap is just space between programmed ships. It is not an object that must shrink as it moves. The string is an object. Relativity says its natural length, measured from the launch frame, becomes shorter as its speed rises. Holding it across the unchanged gap stretches it."
resolution:
  - "An unchanged gap does not mean an unstretched string. As the ships gain speed, the string is held longer than its natural moving length. If they continue far enough, it breaks."
  - "In a frame moving with the ships, the description differs: their separation grows. Both descriptions predict stress in the string. Keeping their separation fixed in their own view would require the front ship to accelerate more gently than the rear ship."
finePrint: "The “launch frame” is the viewpoint in which both ships begin at rest. Moving observers disagree about which distant events happen simultaneously, so fixed separation in that frame need not mean fixed separation in a frame moving with the ships. A string’s material strength and the acceleration determine when it breaks; a small increase in speed need not snap it. Dewan and Beran described the puzzle in 1959 and Bell popularised it in 1976. Some authors who agree on the breaking dispute whether length contraction should be called its cause. The entry gives the standard kinematic explanation, not a model of a particular material."
