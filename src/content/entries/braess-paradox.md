problem: Can building a new road make everyone's journey slower?
claimA: More road can only help drivers.
claimB: When every driver picks their own fastest route, a new road can make all of them slower.
verdict: Yes. Everyone's best choice is not the best choice for everyone.
whatBreaks: The idea that when each person chooses what is best for them, the group ends up as well off as it could be.
statusNote: the first claim is wrong, and the reason is well understood and can be checked with simple sums.
setup: "Imagine 4,000 drivers who all want to get from Start to End. There are two routes. Route 1 goes through town A: the first stretch, Start to A, takes the number of cars on it divided by 100 minutes, and the second stretch, A to End, always takes 45 minutes. Route 2 goes through town B: the first stretch, Start to B, always takes 45 minutes, and the second stretch, B to End, takes the number of cars on it divided by 100 minutes. If the drivers split evenly, 2,000 on each route, each journey takes 20 + 45 = 65 minutes. Nobody can do better by switching, so this is where drivers settle."
whyWrong: "Now build a very short link from A to B, taking almost no time. A driver can now go Start to A, across to B, then B to End. While the roads are quiet this looks great, so more drivers try it. Once everyone does, 4,000 cars share the Start to A stretch and 4,000 share the B to End stretch. Each journey takes 40 + 0 + 40 = 80 minutes. Check whether anyone would go back. The old route through A would now take 40 + 45 = 85 minutes, and the old route through B would take 45 + 40 = 85 minutes. So everyone stays on the new link, and everyone's trip is 15 minutes longer than before. If the link were closed, they would all be back to 65 minutes."
resolution:
  - "Nothing is wrong with the sums. The surprise comes from assuming that when each driver does what is best for them, the result is best for everyone. It is not. Each driver on the link saves time for themselves but slows the roads that everyone else uses. Economists call the settled-down state an equilibrium, meaning a situation where no single driver gains by changing route. Braess's point is that this equilibrium can be worse for all than a state without the shortcut."
  - "The German mathematician Dietrich Braess published the example in 1968. Wikipedia says the economist Arthur Pigou described a similar effect in 1920, and the name is a case of a later person getting the credit."
  - "Sources report real cases where closing roads seemed to speed traffic up. These include Seoul, where an expressway was removed in the Cheonggyecheon restoration, and Manhattan, where 42nd Street was closed for Earth Day in 1990. These reports are usually described as consistent with the paradox. They do not prove that it caused the effect in each case."
finePrint: "The numbers are a standard textbook example, chosen so the sums are easy. The effect only appears when drivers choose selfishly and the roads slow down as more cars use them. A new road does not always cause it, and often a new road helps. It is a surprising result, not a contradiction, so it is a paradox only in the everyday sense."
