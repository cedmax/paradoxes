title: "Crocodile dilemma"
titleAccent: dilemma
chapter: self-reference
status: unreconciled
simplification: light
order: 6
written: true
noMaths: true
problem: "A crocodile promises to return a stolen child if the parent correctly predicts what it will do. What should the parent say?"
claimA: "If the parent is right, the crocodile must return the child."
claimB: "If the parent says the child will not be returned, no action by the crocodile is consistent with the promise."
verdict: "No action fits the promise, and no standard fix exists."
whatBreaks: "The assumption that a promise about your own future action can always be kept."
statusNote: "the sources checked offer no accepted solution, and each way out gives up something."
setup: "A crocodile has stolen a child. It tells the parent, I will give the child back if and only if you correctly say what I will do. The parent answers: you will not give my child back. Now the crocodile has to act. If it keeps the child, the parent was right, so by its promise it must return the child. If it returns the child, the parent was wrong, so by its promise it must not."
whyWrong: "The promise looks like a fair, ordinary deal, and so does the prediction. But the prediction is about what the crocodile does with the promise, and the promise is about whether the prediction is right. Each one feeds back into the other, and there is no move for the crocodile that satisfies both."
resolution:
  - "The sources I checked offer no standard solution. Wikipedia describes it as having no justifiable solution and links it to problems of self-reference and of what one can know about one's own actions, as in the unexpected hanging paradox."
  - "The structure is the same as the liar paradox. The promise asks the crocodile to make a statement true that is about itself. The simplest reading is that the promise cannot be kept, so the crocodile cannot be held to it. That fits the logic but leaves the parent worse off, and it does not explain why a promise that sounded fair turns out to be empty."
  - "A different reading says the parent should never give that answer. If the parent says the child will be returned, the crocodile can simply keep it, and nothing contradicts. But that treats the paradox as a trick about word choice and does not make the original situation consistent."
positions:
  - title: The promise is empty
    body: "A promise nobody can keep binds nobody. Cost: it says the crocodile never really promised anything, which is not how the story is told."
  - title: Avoid the trap
    body: "The parent can answer so that the promise stays consistent. Cost: it leaves the hard case, where the parent chooses the troublesome answer, unexplained."
  - title: Treat it like the liar
    body: "Handle it with whatever fix is used for self-referring statements. Cost: there is no agreed fix for those either, so the problem is passed along."
finePrint: "Ancient Greek sources are said to be the first to discuss it. One modern essay suggests it likely began with the Stoic Chrysippus and notes that the satirist Lucian mocks it, but the sources I read do not give the original wording or ancient responses. The positions above are my plain-language reading of the logic and are not taken from a published list, so check them against more specialist sources."
