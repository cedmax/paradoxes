problem: "A crocodile promises to return a stolen child if and only if the parent correctly predicts what it will do. The parent says it will not return the child. What can the crocodile do?"
claimA: "The crocodile can keep its promise whatever the parent predicts."
claimB: "Whatever the crocodile does here, it breaks its promise."
verdict: "The first claim is wrong. When the parent predicts the child will not come back, no action keeps the promise."
whatBreaks: "The assumption that the crocodile can keep its promise whatever the parent predicts."
statusNote: "once the parent predicts the child will not come back, Wikipedia says the crocodile breaks its terms whether it keeps the child or returns it, and that there is “no justifiable solution”. No action is consistent with the promise, so the first claim, that the crocodile can keep it whatever the parent predicts, is the one that fails."
setup: "A crocodile has stolen a child. It tells the parent, I will give the child back if and only if you correctly say what I will do. The parent answers: you will not give my child back. Now the crocodile has to act. If it keeps the child, the parent was right, so by its promise it must return the child. If it returns the child, the parent was wrong, so by its promise it must not."
whyWrong: "The promise looks like a fair, ordinary deal, and so does the prediction. But the prediction is about what the crocodile does with the promise, and the promise is about whether the prediction is right. Each one feeds back into the other, and there is no move for the crocodile that satisfies both."
resolution:
  - "Check both actions. Keeping the child makes the parent right, and the promise then requires the child back. Returning the child makes the parent wrong, and the promise then forbids it. No action fits, so the promise cannot be kept. This is the same answer as for the barber: a rule that can be stated in one sentence is not thereby a rule that can be followed."
  - "Wikipedia says that once the parent gives this answer, “there is no justifiable solution” to what the crocodile should do. It adds that the puzzle exposes some of the logical problems posed by metaknowledge, knowledge about knowledge, and that it is similar in construction to the unexpected hanging paradox. That comparison is about how the two puzzles are built, not about how settled they are: checking both actions, as above, settles the crocodile's case."
  - "The trouble only appears with this one answer. If the parent says the child will be returned, both actions are consistent: returning the child makes the parent right, and keeping it makes the parent wrong. The outcome is logically smooth but cannot be predicted. So the promise is not always empty, but it is not a promise the crocodile can guarantee to keep whatever the parent says."
finePrint: "Ancient Greek sources are said to be the first to discuss it. One blog essay suggests it likely began with the Stoic Chrysippus and notes that the satirist Lucian mocks it, but it is not a scholarly source, and the original wording and ancient responses are not given here."
