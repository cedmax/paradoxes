problem: "Is there a biggest infinity, or a collection of all the infinite sizes?"
claimA: "The collection of all infinite sizes is itself a set, with a size of its own."
claimB: "No infinite size is the largest, so the collection of all of them is bigger than any size in it."
verdict: "The collection of all infinite sizes is too big to be a set."
whatBreaks: "The assumption that every collection, however large, is a set with a size."
statusNote: "the first claim is wrong. Wikipedia describes the paradox as pointing to a mistaken intuition about infinity and sets, not a true contradiction."
setup: "Cantor showed that infinite sets come in different sizes, called cardinalities. Wikipedia states his paradox as: there is no set of all cardinalities. This follows from the fact that there is no greatest cardinal number. In informal terms, the collection of all possible infinite sizes is so infinitely large that its own size cannot be any of the sizes in the collection. The paradox is named for Georg Cantor, who is often credited with first noticing it in 1899, or between 1895 and 1897."
whyWrong: "Cantor’s theorem says that the set of all subsets of any set is always bigger than the set itself. So there is always a bigger infinity, and no set can contain all the infinite sizes. The mistaken intuition is that a collection of all of them must be a set like any other. Wikipedia says the paradox shows that naive set theory, with a careless set of rules, is inconsistent."
resolution:
  - "Axiomatic set theory handles the problem by declaring that the collection of all cardinal numbers is not a set. It is a proper class, a collection too big to be a set. Wikipedia adds that in von Neumann–Bernays–Gödel set theory it follows that this proper class can be matched one to one with the class of all sets."
  - "So there are infinitely many infinities, and the collection of all of them is larger than any of the infinities it lists. Wikipedia says this is what is paradoxical about it, but it is not an actual contradiction. It is a result about what a set is."
  - "Since the cardinal numbers can be lined up by the ordinal numbers, there is also no greatest ordinal number. Wikipedia says that applying this to the [Burali-Forti paradox](burali-forti-paradox) gives another proof that the cardinals form a proper class, not a set."
finePrint: "Wikipedia notes that some mathematicians give the credit for first stating a similar result to Bertrand Russell, in 1899 or 1901, instead of Cantor. This entry keeps to the basic idea. The details of cardinals, ordinals and proper classes are beyond what is covered here."
