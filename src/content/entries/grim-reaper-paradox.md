problem: "An endless line of reapers will each kill a person only if no earlier reaper has. Who kills them?"
claimA: "The person is certain to be killed before 1pm."
claimB: "No reaper can be the one who kills them, because an earlier reaper would always have acted first."
verdict: "Experts offer different fixes, and each drops a different assumption."
whatBreaks: "Which to give up: continuous time, endless chains of causes, or the logic of the set-up itself."
statusNote: "Wikipedia lists several rival diagnoses, and none is presented as settled."
setup: "Imagine an infinite sequence of reapers, each assigned a time to kill one person. Each reaper kills the person only if no earlier reaper has already done so. It is 12pm. The first reaper is set to act at 1pm, the second at 12:30pm, the third at 12:15pm, and so on, each time halving the wait. The person will certainly be killed before 1pm, since some reaper’s time must come. Yet no individual reaper can be the one who kills them, because there is always an earlier reaper who would have done it first. So it seems impossible for the person to survive and also impossible for any reaper to kill them. The puzzle was inspired by J. A. Benardete’s 1964 book Infinity: An Essay in Metaphysics, and Wikipedia says paradoxes of this kind, where each member acts only if no earlier member has, are called Benardete paradoxes."
whyWrong: "The set-up has no first reaper, since each one has an earlier one, and each reaper’s action depends on all the earlier ones. Wikipedia describes Benardete paradoxes as examples of supertasks, the same family as [Thomson’s lamp](thomsons-lamp)."
resolution:
  - "Wikipedia’s article lists several proposed ways out. They differ on what exactly is impossible about the set-up."
positions:
  - title: Time is discrete
    body: "If time comes in separate moments, an infinite number of reapers cannot each have their own time to act within one hour. Cost: Wikipedia notes that the paradox can take forms that do not rely on continuous time. In Benardete’s book, one god throws up a wall if a man travels half a mile, another after a quarter of a mile, another after an eighth, and so on, and discrete time does nothing to stop that."
  - title: No endless chains of causes (causal finitism)
    body: "Every chain of causes must have a starting point, so there cannot be infinitely many reapers whose actions depend on all the earlier ones. All Benardete paradoxes share that feature, so none can happen. It does not force time or space to be discrete, and is consistent with an infinite past as long as it does not mean a backward-infinite chain of causes. Cost: Wikipedia reports that Schmid and Malpass think it carries heavy metaphysical commitments, though others disagree."
  - title: The set-up is logically impossible (Unsatisfiable Pair Diagnosis)
    body: "Nickolas Shackel observes that every Benardete paradox has two conditions: the ordered set has no first member, and for every member, the event happens at it if and only if it happens nowhere earlier. He shows these are formally inconsistent, so no set can satisfy both and no metaphysical thesis is needed. Cost: Wikipedia says it does not help much with probabilistic or rationality versions of the paradox, and it permits time travel in all cases except those where a person could kill their own grandfather."
finePrint: "Wikipedia also describes a fourth proposal, the No-Actual-Infinities principle, which would dissolve all paradoxes about an actually infinite number of things. It is left out of the list above because the article gives no cost for it. The article also covers an argument connecting the paradox to a finite past and to arguments about the origin of the universe. This entry does not take up that argument."
